# SCMS Supply Chain Delivery History Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of SCMS supply chain delivery history data using Python. The objective is to understand delivery performance, identify shipment delays, evaluate vendor reliability, and analyze freight expenditure.

## Objectives
- Analyze overall shipment delivery performance.
- Identify early, on-time, and delayed deliveries.
- Examine delivery delays across different countries.
- Evaluate vendor delivery performance and reliability.
- Compare delivery performance across shipment modes.
- Analyze freight costs and expenditure patterns.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Analysis Areas
1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis
3. Delivery Status Analysis
4. Country-wise Delay Analysis
5. Vendor Performance Analysis
6. Shipment Mode Analysis
7. Freight Cost Analysis
8. Business Insights and Recommendations

## Project File
- `SCM_975 (1).ipynb` – Jupyter Notebook containing the analysis.

## Conclusion
The analysis explores important supply chain performance indicators and highlights patterns in shipment delays, vendor reliability, delivery modes, and freight expenditure. These insights can support better logistics planning and supply chain decision-making.
