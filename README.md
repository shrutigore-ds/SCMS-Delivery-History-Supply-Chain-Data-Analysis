## 📌 About the Project

How efficiently does a global supply chain deliver products?

This project explores SCMS supply chain delivery history data to understand shipment performance, identify delivery delays, evaluate vendor reliability, and examine freight expenditure.

Using Python and data visualization techniques, the project transforms raw delivery records into meaningful business insights that can support better supply chain decisions.

## 🎯 Project Objectives

- 📦 Understand overall shipment delivery performance.
- ⏱️ Identify early, on-time, and delayed deliveries.
- 🌍 Analyze delivery delays across different countries.
- 🏢 Evaluate vendor performance and reliability.
- 🚛 Compare delivery performance across shipment modes.
- 💰 Explore freight costs and expenditure patterns.
- 💡 Develop actionable business insights and recommendations.

## 📊 Key Findings

The analysis examines:

- Overall shipment delivery status.
- Countries with higher delivery delay rates.
- Differences in vendor delivery performance.
- Delivery performance across transportation modes.
- Patterns in recorded freight expenditure.

## 💼 Business Value

The findings can help supply chain stakeholders:

- Identify potential delivery bottlenecks.
- Improve vendor performance monitoring.
- Evaluate transportation strategies.
- Understand freight expenditure patterns.
- Make more informed logistics decisions.
